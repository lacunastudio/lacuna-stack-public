# O que é o Lacuna Stack

> Framework AI-portável pra fundadores AI-native em ano um. Esta página explica o que está no produto pago e qual a diferença pra esse hub público.

---

## O hub público (onde você está agora)

Este repositório contém:

- Os 29 princípios em versão de leitura
- O manifesto Lacuna em 4 variantes
- 8 princípios públicos
- 13 ADRs reais documentando decisões estratégicas
- Esta página de "sobre"

Função: prova de trabalho. Você vê como pensamos, decidimos e operamos. Sem precisar pagar nada.

---

## O produto pago — Lacuna Stack

O produto completo entrega três componentes:

### 1. Manual em PDF (~106 páginas A4)

Sete partes cobrindo:

- **Fundação** — filosofia, 29 princípios completos, manifesto, princípios públicos
- **Método operacional** — fases F0-F4, lentes de novo projeto, distribuição financeira, documentação, versionamento
- **Regras escopadas** — anti-alucinação, design execution, investigar antes, absorção de claims, artefato externo, verificação cruzada, conteúdo público
- **Skills, agentes, hooks** — instrumentação operacional do Claude Code (com versões pra outras IAs)
- **Portabilidade AI** — como adaptar pra ChatGPT, Cursor, Windsurf, Gemini
- **Casos de aplicação** — exemplos vivos
- **Apêndices** — checklists, cheat sheets, glossário, fontes de dados

### 2. Repositório GitHub template clonável

Estrutura operacional completa. Você clica em "Use this template" no GitHub e tem o próprio hub privado com:

- ~95 arquivos meta prontos pra adaptar (princípios, regras, agentes, skills, hooks, metodologias)
- Estrutura híbrida: `projeto/` ativo + `matriz/` e `marcas/` esqueleto pra ativar quando crescer
- Hooks PowerShell + Bash equivalentes (cross-platform)
- SETUP.md com passo a passo da primeira hora
- Etiquetas E/O/EX (essencial / opcional / exemplo) em cada peça

### 3. Bônus — Notion template adaptado

Mesma estrutura conceitual em ambiente Notion. Pra quem prefere começar em interface visual antes de migrar pra ferramentas AI-native.

## Pra quem é

Founders AI-native em ano um. Pessoa que está construindo (ou começando) um projeto próprio, já usa alguma IA pra coding/produtividade, e precisa de método pronto em vez de inventar.

---

## Pra quem não é

- Quem nunca usou nenhuma IA pra trabalho real
- Quem busca fórmula de "ganhar dinheiro rápido"
- Quem prefere customizar tudo do zero como exercício filosófico
